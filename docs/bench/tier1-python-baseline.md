Generated 2026-05-17, workspace at `ff48793` (weld 0.19.1).

This document is the frozen reference for the post-promotion Python
Tier-1 state. It records the per-criterion outcome of
`tools/tier_check.py` against each of the five pinned corpora
declared in [`tier1-corpora.yaml`](tier1-corpora.yaml). It is
intentionally diff-friendly: a future regression to any of the

as a line-level change in this file.

The numbers were generated by running `python3 -m weld discover`
against each pinned corpus at workspace HEAD, followed by
`python3 tools/tier_check.py --language python --corpus <corpus>
--rediscover --json`. See "How to refresh" at the bottom.

## Continuous improvement

All five real-corpus rows now report `verdict='tier1'` at this
workspace SHA. The remaining advisory signals are:

- C6 (description_coverage) is `fail` on every corpus because no
  enrichment provider pass has been run against any of them; this
  is advisory under ADR 0064 and does not gate promotion. Running
  `wd enrich` against a pinned corpus would lift its C6 column to
  `pass` if coverage crosses the 70 % threshold.
- C5 (federation) is `stub` on every corpus because each is run as
  a single-repo target rather than as a polyrepo workspace root.
  This is `acceptable_for_tier1=true` by design; to exercise C5
  end-to-end, a federation-flavoured corpus would need to be added
  to `tier1-corpora.yaml` with `.weld/workspaces.yaml` and
  cross-repo strategies declared.

The Tier-1 declaration for Python is anchored by the bundled
fixture contract gate at `//tools:tier_check_python_gate_test`,
which exercises the strategy stack end-to-end and pins
`verdict='tier1'`. The flask strategy is independently covered by
`//tools:tier_check_python_flask_gate_test` against the bundled
`sample_flask` fixture, so the C3 contract stays green even if a
future corpus refresh changes any single real-corpus measurement.

## How to refresh

The doc above is reproducible from the workspace HEAD plus the five
pinned corpora. To regenerate:

```bash
# 1. Materialise the corpora at their pinned SHAs (idempotent for the
#    polyrepo children; black/django need an out-of-band clone).
python3 tools/tier1_corpus.py --language python --fetch \
    --output /tmp/weld-tier1-corpora-python

# 2. Re-run tier_check against each. --rediscover ensures the corpus
#    graph is built with workspace-HEAD weld (not a possibly-lagging
#    installed wd binary). --json captures the full criterion payload.
for corpus in black django flask httpx poetry; do
    PYTHONPATH=. python3 tools/tier_check.py \
        --language python \
        --corpus /tmp/weld-tier1-corpora-python/$corpus \
        --rediscover \
        --json > /tmp/tc-python-$corpus.json
done

# 3. Inspect verdicts and per-criterion status.
for f in /tmp/tc-python-*.json; do
    python3 -c "import json,sys; d=json.load(open(sys.argv[1])); \
        print(d['corpus'], '->', d['verdict']); \
        [print(' ',k,v['status']) for k,v in sorted(d['criteria'].items())]" \
        "$f"
done
```

Each corpus directory must contain a `.weld/discover.yaml`. The
`tier1_corpus.py --fetch` operation only materialises the polyrepo
children (flask / httpx / poetry) at their pinned SHAs; the desktop
(black) and framework (django) pins need to be cloned out-of-band
(`git clone <url>; git -C <dest> checkout <sha>`) and any corpus
without a discover.yaml needs `wd init <corpus>` before the harness
will produce a non-empty graph.

Workspace SHA, corpus SHAs, kind vocabulary, edge counts, F1
scores, determinism SHA-256s and LOC counts are deterministic and
should reproduce byte-identically when the same discover.yaml is
in place. The `wall_clock` values in the performance criterion are
wall time and will vary by host -- the `seconds_per_100k_loc`
column is bound by the 60 s/100k-LOC budget declared in ADR 0064
and is the field that matters for regression detection.

If any structural fact above changes against the same workspace SHA
and corpus SHA pair, that is a real regression and should be filed
as a bd issue against the Python Tier-1 epic.
